# JANNEH

A lightweight single-page starter app for JANNEH with the requested features:

- Full Qur'an section (text-only placeholder for Arabic + transliteration + translation across 114 surahs)
- Daily verse reminder time saved in local storage
- Hadith library starter entries (text-only)
- Prophets' life stories starter summaries (text-only)
- Du'a reminder timer with start/clear controls
- Islamic motivational quotes rotator
- Prayer tracker calendar log stored locally
- User progress tracker with Hasanat counter stored locally
- Featured note for Qur'anic tutorial by Shaykh Al-Husary

## Logo usage

If you have the final app icon/logo, place it at:

- `./logo.png`

The app will automatically show it. If missing, a JANNEH fallback tile is displayed.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.
